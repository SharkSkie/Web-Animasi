# 🌌 Interactive 2D Solar System Animation

A standalone, interactive, and automated 2D Solar System cinematic web animation built with HTML5 Canvas, CSS3, and JavaScript.

## ✨ Features
- **Accurate & Dynamic 2D Visuals:** Glowing Sun with corona effect, 8 orbiting planets (Mercury to Neptune) with realistic orbital speed ratios, glowing selection rings, and Saturn's rings.
- **Cinematic Auto Tour:** Smooth auto-camera panning and zooming across each planet with detailed informational overlays.
- **Interactive Click & Focus:** Click on any celestial body or planet label to zoom in, view stats, and inspect details.
- **Animated Astronaut Guide:** An animated companion that slides in to deliver planetary facts and witty commentary with typewriter text effects.
- **Pure Web Standards:** Single-file architecture with zero external runtime dependencies.
